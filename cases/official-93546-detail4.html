金融商品取引法違反

上場企業が架空売上約1億3000万円を計上して損失を利益と偽った財務報告をした事件。東京地裁は法人を金融商品取引法違反と認定し、罰金1000万円とした。

求刑・判決

求刑

罰 金 1 0 0 0 万 円

判決

被 告 会 社 を 罰 金 1 0 0 0 万 円 に 処 す る 。

主張と裁判所の判断

検察側の主張

検察側は、上場企業が架空売上の計上などにより実際の損失を利益と偽った財務情報を開示したとして、法人を金融商品取引法違反で起訴し罰金1000万円を求刑した。

被告人・弁護側の主張

法人側に関係する役員らが別会社を利用した架空の取引を計上していた経緯が判決で検討された。法人に対する個別の反論・科刑意見の詳細は判決本文の公開部分から確認できない。

裁判所の判断

東京地裁は、架空売上約1億3000万円を計上するなどした虚偽の財務報告は、企業価値について投資家に誤解を生じさせる危険があり、金融商品取引法違反に当たると認定した。被告法人に罰金1000万円を言い渡した。
